-- Tell me once again why the simulation run takes a while -- don't make any changes as I am running the simulation now
    For each simulated business day, the runner spawns a fresh subprocess which runs the full PortfolioManagerAgent. The slow parts are:
    Research agent — for real tickers on the watchlist (MSFT, AAPL, NVDA, etc.) it makes live web searches and an Ollama LLM call per ticker to generate a BUY/SELL/WAIT recommendation. Mock tickers skip this entirely.
    Buy tech evaluator — fetches OHLCV data and runs indicator calculations for every ticker that passed research.
    Holdings evaluator — for each open holding, evaluates exit conditions. Also calls Ollama for generate_reason on real tickers (mock tickers skip it).
    Subprocess startup overhead — each day is a separate Python process, so interpreter + all imports cold-start every time.
    The mock tickers (DOBBY, OWALA, etc.) are fast — pure local CSV reads with no LLM calls. The real watchlist tickers are what add minutes per day. With 10 business days and several real tickers, the total run could take 20–40 minutes depending on how many end up as BUY candidates.
